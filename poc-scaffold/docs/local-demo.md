# Local Demo Flow

## Intended Demo

1. Start backend.
2. Run agent simulator.
3. Open UI.
4. Review Findings.
5. Open Finding Detail.
6. Create Campaign.
7. Simulate job results.
8. Open Evidence Report.

## Backend Commands

```bash
npm run dev
```

## Agent Simulator Commands

Placeholder:

```bash
PATCHOPS_API_URL=http://127.0.0.1:3000/api node simulator.js
```

## UI Commands

Current prototype:

```bash
open http://127.0.0.1:8765
```

## Review Script

Use this flow with stakeholders:

1. Show Overview for fleet posture.
2. Show Findings for vulnerability exposure.
3. Open Chrome critical Finding Detail.
4. Open Campaign Builder.
5. Show Notifications popup preview.
6. Show Evidence Report.
7. Close on Admin settings to show governance and safety.
