# PatchOps brand mark

The "fleet tile" P: a 4×4 grid of device tiles forming a P, with one tile in blue for the device that
was just patched.

| File | Use |
|---|---|
| `patchops-mark-on-dark.svg` | The mark on navy or dark backgrounds (light tiles, sky-blue accent) |
| `patchops-mark-on-light.svg` | The mark on white or light backgrounds (navy tiles, tide-blue accent) |
| `patchops-icon.svg`, `patchops-icon-512.png`, `patchops-icon-1024.png` | App icon: the mark on a navy rounded square |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab, bookmarks and iPhone home screen |

Colors: navy `#0E2233`, glacier `#EEF3F6`, tide blue `#0B6E99`, sky blue `#7CC4E4`.
Wordmark: "PatchOps" in Instrument Sans, weight 600, letter-spacing −0.025em.
Keep clear space around the mark of at least one tile; don't recolor the tiles individually or rotate it.
