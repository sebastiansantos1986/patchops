# Vendor logos

PatchOps shows a vendor's logo on Integrations, Posture and Data sources when a file with the
right name is in this folder. Without one it shows a monogram (IN, JF, CS…).

| File name (`.svg` preferred, `.png` also works) | Vendor |
|---|---|
| `intune.svg` | Microsoft Intune |
| `jamf.svg` | Jamf |
| `crowdstrike.svg` | CrowdStrike |
| `kandji.svg` | Kandji |
| `workspace-one.svg` | Omnissa Workspace ONE |
| `mosyle.svg` | Mosyle |
| `addigy.svg` | Addigy |
| `agent.svg` | Your own PatchOps agent icon (optional) |

Get each logo from the vendor's official brand or press page and follow its usage guidelines (most ask
you not to recolor or distort it). A square icon or symbol version looks best: it is shown at
32–44 px on a white tile. After adding files, commit them so the hosted dashboard gets them too.
