Tracked Windows updates

Monthly Windows updates are cumulative, and each KB moves Windows to a known build, for example 26100.7171. Enter the build(s) a KB produces and PatchOps marks every PC at or above that build as patched, using the build Intune already reports. Microsoft's Windows 11 update history page lists each KB as "KB50xxxxx (OS Build 26100.xxxx)". Updates that don't change the build (such as .NET) need the optional Intune Remediation script: see docs/fleet-posture.md.
